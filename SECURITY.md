# How to Report a Potential Vulnerability

Confirmed or potential security vulnerabilities in the meta-freescale-distro
layer should be submitted through the
[Issues](https://github.com/Freescale/meta-freescale-distro/issues) page.

For urgent or not-yet-released issues, contact the maintainer listed in the
[README](https://github.com/Freescale/meta-freescale-distro#maintainer). Include:

- The affected layer or distro configuration
- The release branch and the DISTRO in use
- Example configuration, if available

## Branches Maintained with Security Fixes

See the [Yocto Project release list](https://wiki.yoctoproject.org/wiki/Releases).
Security patches are accepted for the LTS releases and the master branch.
